# A [ggplot2](https://ggplot2.tidyverse.org/reference/ggplot2-package.html) theme formatted in the Open Justice Oklahoma style

`theme_ojo` provides a
[ggplot2](https://ggplot2.tidyverse.org/reference/ggplot2-package.html)
theme formatted according to the Open Justice Oklahoma style guide for
web, with sensible defaults.

## Usage

``` r
theme_ojo_base(
  base_size = 16,
  base_family = "Roboto Mono",
  base_line_size = 0.5,
  base_rect_size = 0.5
)
```

## Arguments

- base_family, base_size:

  base font family and size

- base_line_size, base_rect_size:

  base line and rectangle sizes
