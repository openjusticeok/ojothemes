# OJO source text

A function to construct the "Source:" note text

## Usage

``` r
ojo_source_text(source = NA)
```

## Arguments

- source:

  The domain / source of the data. Can be one of "oscn", "ocdc", or
  "ppb" for canned text, NA for no source, or a custom string.

## Value

A string with the source text
